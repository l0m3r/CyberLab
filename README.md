## 🏗️ Архитектура <a name="архитектура"></a>
Ниже представлена схема сети лаборатории (физические и виртуальные машины):
<img width="1622" height="1021" alt="изображение" src="https://github.com/user-attachments/assets/acbf9d07-e406-4533-9c5e-a221ba7ff500" />

**Ключевые элементы:**  
- **Workstation** — управление ВМ, запуск инструментов, анализ логов.  
- **Proxmox** — гипервизор, на котором развёрнуты все виртуальные машины.  
- **pfSense** — межсетевой экран, маршрутизатор, VPN-шлюз.  
- **Kali Linux** — основная атакующая станция (пентест, эксплуатация).  
- **Windows Server 2019** — целевой сервер (AD, IIS, базы данных).  
- **Windows 7** — уязвимый клиент для отработки атак на старые системы.

## 🌐 Сетевой дизайн <a name="сетевой-дизайн"></a>

В лаборатории используется **сегментированная сеть** с изоляцией трафика:
- **WAN-интерфейс pfSense** подключается к физической сети.  
- **LAN-интерфейс pfSense** (10.10.10.0/24) — внутренняя сеть, где находятся все ВМ.

**Маршрутизация:**  
- Все ВМ имеют шлюз по умолчанию 10.0.0.1.  
- pfSense выполняет NAT для выхода в интернет.  
- Правила межсетевого экрана настроены так, чтобы разрешать только необходимые порты (SSH, RDP, HTTP/S).
